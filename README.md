# Michael Merin Portfolio

A two-color flat portfolio experience focused on motion, interaction, and storytelling. Built as a single-page personal website with animated sections, responsive design, and custom UI details.

## Overview

This portfolio showcases my work as a Front-end Web Developer with a strong focus on:
- rich motion and interaction design
- clean, experimental UI composition
- responsive layouts and visual storytelling
- modern front-end implementation using AngularJS + GSAP

The project is designed as a highly visual landing page with layered motion, custom illustrations, and interactive experience blocks.

## Features

- Animated single-page portfolio experience
- GSAP-powered transitions and motion effects
- AngularJS-driven dynamic content
- Responsive layout system with breakpoint-driven UI states
- 3D-style visual experimentation with Three.js
- Custom sound and interaction feedback
- Flat two-color design language with bold typography and visual hierarchy

## Tech Stack

- HTML5
- CSS3 / SCSS
- JavaScript
- AngularJS
- GSAP
- Three.js
